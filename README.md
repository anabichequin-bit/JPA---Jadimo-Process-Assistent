# JPA
Sistema de automações internas desenvolvido para otimizar processos operacionais e reduzir tempo manual.

Automação de Malotes – Separação de Dados para Logística

Trabalho em uma empresa de logística, e no meu dia a dia eu gastava horas organizando manualmente uma planilha que eu recebia por e-mail. Era um processo repetitivo e demorado, então decidi criar minha primeira automação para resolver isso. A automação lê a planilha recebida e separa os dados por categoria, gera automaticamente a planilha final organizada e possui interface gráfica simples para facilitar o uso por outras pessoas do setor.

Tecnologias usadas: python, streamlit, pandas e openpyxl. 

Como usar: baixe os arquivos do repositório, execute o arquivo .bat ou rode o .py e selecione as planilhas quando a janela abrir.
